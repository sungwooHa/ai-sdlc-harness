# ADR-0001: 오래 유지할 결정과 이유는 저장소에 남긴다

- 상태: accepted
- 날짜: 2026-09-14
- 대체함: 없음
- 대체됨: 없음

## 배경

변경별 문서를 모두 저장하면 리뷰 비용이 커지지만, PR에만 이유를 남기면 다음 작업에서
결정 배경과 포기한 대안을 다시 찾아야 한다. 현재 규칙만으로는 왜 그 규칙이 생겼는지 알기 어렵다.

## 결정

여러 작업에 영향을 주는 구조·계약·운영·하네스 결정은 docs/decisions의 짧은 ADR로 추적한다.
일회성 spec/plan/HTML·실행 로그는 기존대로 로컬 변경 폴더와 PR에 둔다.
새 결정은 구현 전 합의에 포함하고, 기존 결정 변경은 새 ADR로 대체 관계를 남긴다.

## 검토한 대안

- PR에만 기록: 저장소는 가벼우나 현재 유효한 결정과 이유를 찾기 어렵다.
- 모든 작업 문서 커밋: 맥락은 많지만 중복·리뷰 비용이 커진다.
- 모든 PR에 ADR 의무화: 사소한 작업까지 형식적인 문서를 늘린다.

## 결과와 감수한 비용

새 사람이 선택 이유를 복원하기 쉬워진다. 문서를 최신 결정과 연결하고 대체 상태를 관리하는
비용은 생긴다. ADR 대상인지와 근거의 충분성은 사람이 검토해야 한다.

## 재검토 조건

의미 없는 ADR이 반복되거나, 중요한 결정이 계속 누락되거나, 현재 유효한 결정을 찾기 어려워지면
작성 기준과 목록 관리 방식을 조정한다.
